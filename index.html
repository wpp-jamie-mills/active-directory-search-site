Claude Desktop extension for macOS

Ask Claude about your Entra ID directory.

It finds people, groups and distribution lists, reads account status, email aliases and reporting lines, and never changes anything. One command installs it, and the same command updates it.

Install Guide for AI agents

Version 1.6.1macOS · Claude DesktopRead-only

Install

One command, then two clicks in Claude Desktop

The installer downloads the latest extension, checks its SHA-256 before anything changes, opens Claude Desktop's install dialog, and waits until the extension is switched on and running. Click Install there; you choose your work account the first time you sign in.

For people

Open Terminal and run:

Terminal
curl -fsSL https://wpp-jamie-mills.github.io/active-directory-search-site/install.sh | bash

You need a Mac with Claude Desktop 2.7032.0 or later and a Microsoft 365 work account. You don't need Python, Node, git or a configuration file. After that it keeps itself up to date: Claude offers each new version on an update card in the chat, and it is installed only when you click Update now and then Install. Your settings and your sign-in are kept.

Then

  1. Click Install in the dialog Claude Desktop opens. You can leave its settings blank: you choose your work account the first time you sign in. Fill in the WPP tenant only if you also want to search the WPP directory.
  2. If Claude Desktop shows the extension switched off, switch it on: Settings > Extensions > Entra Directory Search for Claude Desktop.
  3. Start a new chat and ask something, for example "Who does Alex Smith report to?". The first time, Claude shows a sign-in card: enter the code on the page that opens, sign in with your work account, and Claude carries on.

For AI agents

Use these steps if you are an AI agent installing this for a user.

A plain-text version is in llms.txt.

  1. Check the machine. Continue only if uname -s prints Darwin and /Applications/Claude.app exists. Otherwise tell the user it needs a Mac with Claude Desktop 2.7032.0 or later.
  2. Run the installer with this one command. It downloads the extension, checks its SHA-256 (nothing changes before the check passes) and opens Claude Desktop's install dialog. With no terminal it never prompts, and --no-wait makes it exit once the dialog is open. It exits non-zero, with the reason on stderr, if anything fails.
Terminal
curl -fsSL https://wpp-jamie-mills.github.io/active-directory-search-site/install.sh | ADSEARCH_INSTALL_TTY=/dev/null bash -s -- --no-wait
  1. Hand over to the user. Ask them to click Install in the dialog Claude Desktop opened (they can leave its settings blank), and to switch the extension on if Claude Desktop shows it off (Settings > Extensions). You can't do these for them.
  2. Verify. Run the installer again with --status (after bash -s --). It should show Ready: yes; otherwise its Next: line says the one thing left to do. Then ask the user to start a new chat (chats opened while the extension was off don't see its tools) and say "Sign in to Entra Directory Search".
  3. Updates look after themselves. Once a day the extension checks for a new version and Claude shows the user an update card. Only the user can click Update now and then Install; to update straight away, run the install command again.

Read-only by design

The server exposes read-only directory lookups. It never creates, changes or deletes users, groups, memberships, policies or authentication methods.

Your organisation's usual sign-in

You sign in with a short code in your normal browser, so your organisation's MFA applies as usual. The refresh token is kept in your macOS Keychain and never in the extension.

Finds users, groups and reporting lines

Search users by name or email, inspect managers and direct reports, and expand nested distribution lists.

Checked before it installs, and offers its own updates

The installer verifies the download before anything changes, then Claude Desktop's own dialog shows the tools and settings before you click Install. New versions are checked the same way and offered on a card in the chat; nothing installs until you agree.

  • SHA-256Checked before anything changes
  • Update nowNew versions offered in the chat, installed only if you agree

Features

What it can and can't do

  • Can: search users by name, read a user's profile, account status and expiry, email aliases, groups, manager, direct reports and peers; read groups and expand distribution lists, nested lists included; check membership; search recently deleted users. Temporary access passes and conditional access policies are read only when your account holds a role that allows it, such as Security Reader.
  • Can't: create, change or delete anything: users, groups, memberships, policies or authentication methods. It reads only what your own account may read.
  • Your data: directory details Claude reads are sent to Anthropic as part of your conversation, under your Claude account's terms.

Sign in and sign out

You normally never need to think about it: Claude asks you to sign in when Microsoft needs a new sign-in, and remembers you until then. To do it yourself, say "Sign in to Entra Directory Search" (or "… to the WPP directory"), or "Sign out of Entra Directory Search" to forget a saved sign-in.

The sign-in card shows a one-time code, an Open sign-in page button and a live status. Your browser also opens at Microsoft's device sign-in page, and the code is already on your clipboard.

  1. Paste or type the code on that page.
  2. Sign in with your work account, as your organisation normally asks (MFA included).
  3. Approve "Microsoft Office" when asked.
  4. Come back to Claude. The card turns to Signed in and Claude carries on with your question.

The code works for 15 minutes. If it expires, ask Claude to sign in again for a new one.

Settings

Profiles and settings

Every setting is optional. Add the WPP tenant to search a second directory alongside your own.

The extension's settings (Settings > Extensions > Entra Directory Search for Claude Desktop > Configure) are all optional:

SettingWhat it does
Default sign-in emailAllows only this account for the default profile. Blank: any work account you sign in with
Default Entra tenantYour organisation's tenant id or domain. Blank: Microsoft's work-account sign-in
WPP sign-in emailAllows only this account for the WPP profile
WPP Entra tenantTurns on the wpp profile, for example wpp.com. Blank: no WPP profile
Check for updatesChecks the landing page once a day and offers new versions (on by default)

Each profile signs in separately and keeps its own sign-in in your macOS Keychain. Ask Claude to use the WPP directory and it passes profile: "wpp"; otherwise it uses the default account.

Safety

Read-only by design

This extension never changes users, groups, memberships or policies.

There are none. The extension is read-only: every directory tool only reads, and no tool can change your directory.

Security

Sign-in and privacy

How you sign in, where the sign-in is kept, and what Claude can see.

  • The extension signs in as the pre-approved Microsoft Office app with your own account, using Microsoft's device-code sign-in: you enter a short code in your normal browser, so your organisation's usual sign-in and MFA apply.
  • After you sign in, Microsoft issues a refresh token. It is stored only in your macOS login Keychain, as the item active-directory-search-refresh-token, one entry per profile; never in a file or in the extension. Access tokens stay in memory.
  • If you set a sign-in email, signing in as any other account is refused.
  • Only enter a code that Claude has just shown you, when you asked Claude something. Never enter a code someone sends you: that would sign them in as you.
  • The installer checks the download's SHA-256 before anything changes and never reads or prints your sign-in.
  • Once a day the extension asks the landing page which version is the latest; nothing about you is sent. Its update card checks the new version's SHA-256 too and only opens Claude Desktop's install dialog: nothing is installed until you click Install.

Update

Update and remove

It checks for new versions itself and asks you first. Updating keeps your settings and your sign-in.

The extension checks the landing page once a day while Check for updates is on. When there is a new version, Claude shows an update card: Update now downloads it, checks its SHA-256 and opens Claude Desktop's install dialog; Not now hides that version for a week. Running the install command again also updates. Your settings and sign-ins are kept.

To remove it, say "Sign out of Entra Directory Search" (once per profile), uninstall it in Claude Desktop (Settings > Extensions), then remove the download folder:

Terminal
curl -fsSL https://wpp-jamie-mills.github.io/active-directory-search-site/install.sh | bash -s -- --uninstall

One command to install. Updates come to you.

No Python, Node or configuration files. Claude offers each new version on a card in the chat, and nothing installs until you agree.
